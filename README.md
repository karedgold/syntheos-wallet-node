# Monedero Nodo Syntheos

Repositorio de distribución del Monedero Nodo para Windows.

**Versión disponible · v0.8 en modo de prueba**

[Descargar el Monedero Nodo para Windows](downloads/Monedero_Nodo_Syntheos_Windows.zip?raw=true)

Extrae el ZIP y ejecuta `Abrir-Monedero-SIL.cmd` con Node.js 24. Consulta `LEEME.md` dentro del paquete para configurar el nodo y consultar los recibos PoUW.

Los saldos, la minería de Génesis 0 y la liquidación de cómputo son simulados.
