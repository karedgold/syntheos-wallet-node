# Monedero Nodo Syntheos

Repositorio de distribución del Monedero Nodo para Windows.

Descarga el ZIP en [la última publicación](../../releases/latest). Extrae el paquete y ejecuta `Abrir-Monedero-SIL.cmd`. El monedero requiere Node.js 24. Consulta `LEEME.md` dentro del ZIP para configurar el nodo.

La versión v0.8 funciona en modo de prueba. Los saldos, la minería de Génesis 0 y la liquidación de cómputo son simulados.
